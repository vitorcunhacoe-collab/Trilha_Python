Esse código pode servir para organizar projetos muito grandes e com muitas pastas, a primeira coisa é salvá-lo como automatizador_gitkeep.py dentro da pasta principal do projeto a ser organizado, no terminal navegue até a pasta e use o comando: "python automatizar_gitkeep.py". O projeto vai ser organizado e um relatório será gerado na pasta "logs".
Pergunta 1: Ambas pegam um dado, seja lista, dicionário, variável, etc e trnaformam no formato JSON. A diferença é onde esses dados transformados são guardados. o json.dump() joga a informação em um arquivo aberto enquanto o json.dumps() guarda o código como string pra vc fazer o que quiser.
Pergunta 2: Ambas fazem o caminho contrário, pegam um dado em JSON e transformam em um dado em python. O json.load() carrega as informaçoes de um arquivo e o json.loads() carrega as informações de uma string
